### 🧬 About

I'm an Informatics Engineering student (UCSE, Argentina) focused on **full-stack development** and **applying AI in practical, local-first ways** — not training models, but integrating LLMs into real tools that people actually use day to day. My flagship project, **CelestIA**, runs a local LLM through a WhatsApp interface to manage a personal knowledge vault — no cloud APIs, no data leaving the machine.

I enjoy working across the stack: designing relational databases, building REST APIs, and wiring backend logic to automation layers. Lately I've been moving client projects off managed platforms (Supabase, Vercel) onto my **own self-hosted VPS** — Docker, Coolify, hardened SSH, Tailscale — and building a reusable backend to serve all of them from one place. I'm also expanding into **cybersecurity applied to web systems**, building on OS-security and networking fundamentals from my coursework (RSA, TCSEC/Common Criteria, firewall policy design).

### 🚀 Featured Projects

<details>
<summary><strong>🌘 CelestIA — Local-AI WhatsApp Assistant</strong></summary>
<br/>

A personal AI assistant living inside WhatsApp: it decides where to file notes in an Obsidian vault, answers questions using only vault content, transcribes voice messages, and edits notes on command — entirely on a local LLM, no cloud dependency.

| | |
|---|---|
| **Stack** | Node.js, Baileys (WhatsApp Web API), Ollama, Obsidian Local REST API, whisper.cpp |
| **Scale** | Single-user personal system, modular menu-based architecture |
| **Security** | Allow-listed phone numbers only; silent-ignore for unauthorized senders; automatic backups before every edit; write-cancel safeguard if AI output looks truncated |
| **Impact** | Turned a static notes vault into a conversational, voice-capable second brain |
| **Repository** | [Najovi/celestia](https://github.com/Najovi/celestia) |

</details>
